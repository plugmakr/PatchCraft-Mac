Circles (Circle View)

Edit the same five phrase slots as Patterns — but with a Patterning-inspired circular interface: orbit lanes, ring steps, velocity/gate/chance bands, and FX group mutes for live performance.

Studio toolbar tab: Circles Arp Studio mode CircleSEQ Player templates
01

Overview

Circles is the second face of the MIDI Playground workspace. Where Patterns emphasises linear grids and piano-roll editing, Circles emphasises radial step editing, lane selection, and performance-oriented routing (FX throws, harmonic mutes, filter motion).

The header reads CIRCLE PATTERN VIEW. Subtitle reminder: sound still comes from DSP, Sample Mapper, or FX input — Circles shapes when and how hard notes or slices fire, not the raw timbre.

Same data model

Five slots (mpBank1…mpBank5) shared with Patterns. Edit in either view.

Circle-native UX

Ring step matrix, lane list, step inspector, and mini orbit previews per lane.

Player-ready

CircleSEQ templates drop Arp Lane widgets on the canvas with multi-ring orbit display.

Naming map

UI labels: Circles tab · Circle View toggle · internal block type arpSequencer · canvas element Arp Lane / CircleSEQ · research name Orbit Lane.

02

Opening Circles

  1. Click the Circles tab in the canvas toolbar (after Patterns).
  2. Or open Patterns and toggle Circle View in the header (same page, different mode).
  3. Confirm title CIRCLE PATTERN VIEW and Circle View toggle is active.

From Design:

  • Right-click canvas → Add Arp Studio Lane or Add CircleSEQ Musical Surface.
  • Select an Arp Lane element → Inspector → jump to Circles to edit its pattern ring.
  • Menu item Build Ring (Inspector) writes Patterning-style lane metadata into the active phrase bank.
03

Circle workflow

The active summary strip describes the intended path:

  1. Build Sound in DSP Finish your instrument chain first. Circles triggers notes/slices into that engine.
  2. Pick a Slot Use the Slot dropdown (phrase bank 1–5) or click a lane in the left column. Each slot is an independent circle pattern.
  3. Edit the ring / steps Use the step editor matrix (Note, Velocity, Gate, Chance) or click steps on the large ring for the selected lane type.
  4. Assign lane target Per-lane Source and Target (filter cutoff, volume, sample slice, etc.) define what the lane modulates or triggers.
  5. Make Circle Pattern Writes all five slot runtimes into the DSP graph — equivalent to Patterns’ “Use This Pattern” but for the CircleSEQ data shape.
  6. Update Player Controls Applies the CircleSEQ Flagship Player layout (or refreshes existing Arp Lane widgets).
04

Lanes & slots

The left column lists five lanes, each mapped 1:1 to a phrase slot. Click a lane row to select it; the step editor and orbit preview update to that slot’s data.

Lane names (default roles)

LaneDefault roleTypical target
1 · LeadMelodic/arpeggiated lead lineSynth pitch / sampler notes
2 · HarmonyChord tones or pad movementVoiced notes or filter
3 · BassLow-end rhythmMonophonic bass notes
4 · DrumsPercussion triggersDrum pad notes / samples
5 · FXThrows, fills, modulationSlice index, FX send, mute groups

Selected lane source panel

Bottom-left card:

  • DSP — which engine section the lane feeds (stored in lane metadata for export).
  • Target — parameter or trigger type (Filter Cutoff, Volume, Sample Slice, Sample Start/Length, Wavetable Position).

Player preview currently auditions one active slot at a time; lane source choices are persisted for builder/export either way.

05

Ring step editor

The central Step Editor shows up to 64 steps in four horizontal bands: Note, Velocity, Gate, and Chance (probability).

Mouse editing

  • Click / drag in a band to set value for that step (vertical position = amount).
  • Ctrl-click or right-click toggles step on/off without changing values.
  • Active steps use brighter fill; inactive steps appear dimmed but retain stored values.
  • Playback highlights the current step when Play Pattern is running.

Step Inspector (right column)

When a step is selected, the inspector shows:

  • Lane name and index
  • Step number (1-based display)
  • Velocity (0–127)
  • Gate length (percentage of step)

Large orbit preview

The main canvas ring visualises the selected lane’s active steps as dots around a circle. Playhead motion during preview rotates through steps clockwise — matching how the Player renders Arp Lane widgets.

06

Project strip above the editor also exposes Slot, Key, Scale, and UI template in one row for fast context switches.

07

FX group routing

The FX Group Routing panel defines five performance mute/throw groups used in CircleSEQ layouts:

  1. Group 1 — Harmonic mute — silence or duck harmonic content
  2. Group 2 — Delay throw — send bursts to delay line
  3. Group 3 — Reverb space — widen or wash the tail
  4. Group 4 — Filter motion — sweep cutoff or brightness
  5. Group 5 — Gate/pulse — rhythmic chopping or tremolo

Each group displays its routing mode and accent colour in the panel. Map these to macros or pScript in Brand Lab for custom performance behaviour.

08

Orbit & multi-ring modes

On the Design canvas, Arp Lane elements support advanced orbit display modes via Inspector:

  • Single ring — one note/slice per step around the circle.
  • Multi-ring / Orbit — concentric rings show sample slots, drum voices, or pitch layers simultaneously.
  • Direction — clockwise / counter-clockwise step advance.
  • Rotation — phase offset for the pattern start point.
  • Euclidean pulses — evenly spaced hits independent of manual step toggles.
  • Fill pulses / fill probability — secondary layer for variation fills (Patterning-style).
Sample & drum lanes

When a lane targets samples or drums, orbit view draws multiple concentric rings so you can see which slice or pad each step triggers. Set per-step slice index in the Note band or bind to Sample Mapper pad layout.

09

Design canvas elements

Arp Studio Lane

Compact circular widget for the Player. Binds to one phrase slot index (arpLaneIndex). Supports click-to-toggle steps, drag for velocity, and MIDI drag-out in Studio preview.

CircleSEQ Musical Surface

Full flagship layout: multiple lanes, orbit rings, transport, and slot switching — generated by Update Player Controls with the CircleSEQ GUI template.

Context menu pattern clipboard

Right-click a selected Arp Lane in Design:

  • Copy Circle Pattern
  • Paste Pattern To This Circle
  • Reset Circle To No Sound

11

MIDI drag to DAW

Each lane row exposes a MIDI drag handle. Click and drag from that region into your DAW to drop a MIDI clip representing the selected slot’s pattern (notes, velocities, and step timing).

  1. Select the lane / slot you want to export.
  2. Press and hold on the lane’s MIDI drag zone until the drag threshold is met.
  3. Drop onto a DAW MIDI track for further editing or layering.

Alternatively use Export MIDI in the header action row for a file-based export of the active slot.

12

Output contract

The Output Contract panel summarises what Circles commits to disk:

  • Make Circle Pattern — serialises all five slot runtimes (mpBank* keys) into the DSP block.
  • Update Player Controls — writes/updates layout elements bound to lane parameters.
  • Export MIDI — standard MIDI file for external DAWs.
  • Export Center — packages block + layout + manifest into the shippable .patchcraft folder.
Runtime behaviour in Player

The Player’s MidiPlaygroundRuntime reads the same bank keys as Studio. Circle widgets show live playheads; hardware MIDI and host transport advance steps at the synced project BPM.

13

Patterns ↔ Circles sync

Both tabs edit one shared MIDI Playground block. Rules of thumb:

  • Switching tabs does not duplicate data — it changes the editing UI only.
  • Phrase slot N in Patterns equals Lane N in Circles.
  • Linear piano-roll edits in Patterns appear in the Circle step matrix after refresh.
  • Drum Machine mode is Patterns-first; use Circles for melodic/sample orbit lanes.
  • Always press Make Circle Pattern or Use This Pattern before export — whichever view you edited last still needs an explicit commit if you changed data.

Troubleshooting

SymptomFix
Circles tab missingUpdate Studio — restored in canvas toolbar after Patterns tab.
Ring empty but Patterns has notesSelect correct slot; press Make Circle Pattern; check step On flags (Ctrl-click toggles).
Lane clicks don’t change soundPreview plays active slot only — switch Slot dropdown or assign lane in Player UI.
Orbit rings not visible in PlayerSet Arp Lane mode to Orbit/Multi-ring in Inspector; Update Player Controls.
MIDI drag doesn’t startDrag from the lane’s MIDI zone (not the step matrix); hold until cursor changes.
FX groups do nothingMap group macros to real DSP parameters; verify pScript or mod matrix routing in Graph.
