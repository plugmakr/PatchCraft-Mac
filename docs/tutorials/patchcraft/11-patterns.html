PatchCraft · Workspace 03 · Patterns

Patterns (Pattern Builder)

Author deterministic MIDI performances for your instrument — melodies, chords, arps, sample chops, and drum grooves — then commit them to the pack with Use This Pattern and ship them in the Player.

Studio toolbar tab: Patterns Pairs with Circles tab No random — stable every play
01

Overview

Patterns is PatchCraft’s linear pattern workspace (internally called Pattern Builder). It lives on the same engine as Circles but optimises for step grids, piano roll editing, drum machines, and musical preset drops.

Sound always comes from your current DSP graph, sample map, or FX chain. Patterns does not generate audio — it generates note events, slice triggers, and modulation lanes that drive what you already built.

What you edit

Step on/off, pitch, velocity, gate, probability, slice index, and modulation targets per step.

What gets exported

MIDI Playground DSP block data, phrase bank slots, and optional Player GUI controls from templates.

Relationship to Circles

Same five phrase slots. Switch to Circles for ring editing; changes sync back to the active slot.

Deterministic by design

Musical Tools (transpose, invert, retrograde, scale-quantize) and authored presets never use random number generators. A pattern you hear in Test is the same pattern your customers get in the exported Player.

02

Opening Patterns

  1. Open PatchCraft Studio and load or create a project.
  2. Click the Patterns tab in the canvas toolbar (between One-Shots and Circles).
  3. Confirm the header reads PATTERN PLAYER and the view toggle shows Pattern Builder selected.

Alternative routes:

  • Design → canvas right-click → Add Arpeggiator (MIDI Playground) — inserts a runtime block and jumps you into pattern authoring.
  • Inspector on an existing MIDI/arp element → open Patterns to edit its backing data.
03

Core workflow

The summary strip at the top of Patterns encodes the intended path:

  1. Build Sound in DSP Create or refine your instrument in the Graph workspace — sampler zones, synth patch, drum kit, or FX chain. Use Build Sound in the source panel to jump to Design/Graph.
  2. Choose or author a pattern Pick a Drop Preset musical idea, use Chords / Sample Chops / Drums quick actions, or paint steps in an editor view.
  3. Use This Pattern Commits the current editor contents to the active phrase slot and marks the MIDI block as part of the instrument. This is the “make it real” button — until you press it, edits may be preview-only.
  4. Add Player Controls Applies a GUI template (performance strip, drum pads, macro panel, etc.) so end users can switch slots and perform in the Player.
  5. Test in Player Opens Branding Lab preview with live audio so you can verify timing, gates, and slot switching.
04

Editor views

Select the editor from the View dropdown (hidden automatically in Drum Machine mode).

Step Grid (Output Lane)

Four horizontal lanes per step: Note, Velocity, Gate, and Probability. Click a cell to set pitch or drag vertically within a lane to sculpt velocity/gate/probability curves.

  • Best for arps, bass lines, and modulation lanes where step timing matters more than pitch contour.
  • Gate length is editable by horizontal drag within the gate row.

Piano Roll

Six-octave roll centred on the current root (−36 to +36 semitones). Click empty grid to add a note; click an existing note to remove it. Drag horizontally to extend note length (gate). A mini keyboard gutter shows C labels for orientation.

  • Ideal for chord beds, melodies, and progressions dropped from presets.
  • Hover highlights preview pitch before you click.

Drum Pattern Grid

Appears when Mode is set to Drum Machine (or the active block is a drum machine). Tracks map to kit voices; velocity is set by vertical position within a cell.

  • Eight patterns (Pattern 1–8) per drum block — switch with the Pattern dropdown.
  • Drum-specific Musical Tools: copy/paste pattern, shift steps, accent downbeats, ghost notes, trap hat rolls.

06

Harmony & presets

Drop Preset (musical ideas)

One-click authored content grouped by category:

  • Chords — major/minor triads, 7ths, extended voicings
  • Progressions — pop, jazz, cinematic, trailer movement
  • Melodies + Bass — trance arp, acid line, anjuna lead, walking bass
  • Drum Grooves — trap, four-on-the-floor, DnB, UK garage
  • Sample Remix — chopper and glitch gate performances

Select a preset, then click Use This Pattern to write it into the active slot.

Root, scale, and progressions

  • Root — transposes authored content to the chosen pitch center.
  • Scale — constrains quantize operations and some preset voicings (Major, Minor, Dorian, Blues, etc.).
  • Progression dropdown — applies named chord sequences into the piano roll.
  • Chords button — quick entry to chord phrase configuration.

08

Musical tools (operators)

Open Musical Tools for deterministic transforms on the current pattern:

Melodic / step patterns

  • Transpose — ± octave, ± fifth, ± semitone
  • Invert — mirror intervals around root
  • Retrograde — reverse step order
  • Scale-quantize — snap all pitches to the selected scale
  • Compress to one octave
  • Activate every step / every other step / clear all

Drum patterns

  • Copy / paste / duplicate pattern across pattern slots
  • Shift left or right by one step
  • Accent downbeats, add ghost notes, add trap hat rolls
  • Clear current pattern
Phrase library

Phrase Library exposes hand-authored grooves beyond the Drop Preset list. Use it when you want a finished phrase as a starting point, then apply Musical Tools to customise.

09

Phrase slots (banks)

PatchCraft stores five phrase slots per MIDI Playground block. The Slot dropdown selects which bank you edit.

  • Save Slot — snapshots the current editor into the selected bank.
  • Duplicate Slot — copies the active bank to the next free slot.
  • Switch slots in the Player via key switches or GUI controls added by templates.

Circles view edits the same slots with a ring UI — see Circles documentation for lane targeting and orbit modes.

10

Templates & Player UI

Make Pattern (MIDI template)

Creates or replaces the MIDI Playground DSP block with a configured pattern module:

  • Melodic Lead Line, Cinematic Chord Bed, Drum Pattern, Sample Chopper, Glitch Gate
  • Polymeter Key-Switch Banks, MIDI Echo Throw, Pattern Morph Performance
  • Chord Pad Performer, Riff Generator, Advanced Arp Instrument

Add Player Controls (GUI template)

Generates canvas elements wired to pattern parameters:

  • Performance Strip, Sample Controls, Drum Pad Panel, MIDI Macro Panel
  • XY Performance Pad, Drum Song Controls
CircleSEQ templates

CircleSEQ Flagship Instrument and CircleSEQ Flagship Player belong to the Circles workflow. Use them from the Circles tab — see Circles → Templates.

11

Preview & export

  • Play Pattern / Stop — auditions the active slot with the current DSP sound inside Patterns.
  • Export MIDI — writes a Standard MIDI File of the current pattern for your DAW.
  • Test in Player — full instrument preview with keyboard and transport.
  • Export Center — packages the MIDI block, phrase banks, and GUI into the .patchcraft folder.
Typical pack contents (pattern layer) 
dsp/graph.json          → midiPlayground or arpSequencer block
dsp/blocks/*.values     → step notes, gates, velocities, probabilities
phrase_banks/           → five slot snapshots (mpBank1..5)
layout/                 → optional performance controls from GUI template
pscript.txt             → optional script hooks (note starts, knob moves)
12

Canvas widgets (Player surface)

From Design, add pattern-related elements that bind to the same runtime data:

  • Piano Roll widget — on-canvas step sequencer for end users (Player + Branding preview).
  • Drum Grid — 16×step drum matrix with bank switching.
  • Arp Lane / CircleSEQ — circular lane displays; edit in Circles, perform in Player.

Right-click a selected Arp Lane in Design for Copy Circle Pattern, Paste Pattern, and Reset Circle.

Troubleshooting

SymptomFix
No sound when playing patternBuild DSP first; confirm a MIDI block exists (Make Pattern); check Test audio is running.
Edits disappear after reloadPress Use This Pattern and save the project.
Wrong editor visibleDrum mode hides piano roll — set Mode to Arp/Step or Chord for melodic editors.
Pattern differs in PlayerEnsure you committed the correct phrase slot; verify slot switch controls in Brand Lab.
Can't find Patterns tabUpdate Studio — tab lives in canvas toolbar between One-Shots and Circles.
