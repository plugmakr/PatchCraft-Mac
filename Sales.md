# PatchCraft - Professional Sample Instrument Platform

## 🎵 Overview

PatchCraft is a revolutionary two-part platform for creating and selling professional sample instruments. Designed for sound designers, composers, and music producers, PatchCraft combines the power of a visual instrument designer with a universal player plugin.

**🏗️ PatchCraft Studio** - Visual instrument design environment  
**🎹 PatchCraft Player** - Universal VST3 plugin player

---

## ✨ Core Features

### 🎨 Visual Instrument Designer
- **Drag-and-Drop Canvas** - Intuitive visual layout system
- **Rich Component Library** - Knobs, sliders, buttons, XY pads, keyboards, meters
- **Real-time Preview** - See your instrument come alive as you build
- **Professional Knob Builder** - Create custom knob filmstrips with live preview
- **Layer Management** - Advanced z-order and grouping controls
- **Responsive Layout** - Automatic scaling for different screen sizes

### 🎹 Universal Player Plugin
- **Single Plugin, Infinite Instruments** - One VST3 loads any .patchcraft pack
- **Runtime UI Rendering** - Custom interfaces rendered at load time
- **DAAW Integration** - Full automation, MIDI, and preset management
- **High Performance** - Optimized for real-time audio processing

## 📊 Technical Specifications

### 🖥️ System Requirements
- **Windows 10+** (64-bit)
- **macOS 10.15+** (Intel/Apple Silicon)
- **4GB RAM Minimum** (8GB+ recommended)
- **VST3 Compatible DAW**

### 🎛️ Audio Specifications
- **Sample Rate**: 44.1kHz - 192kHz
- **Bit Depth**: 16/24/32-bit
- **Channels**: Mono/Stereo
- **Voices**: Up to 64 polyphonic
- **Latency**: < 2ms at 44.1kHz

### 📁 File Formats
- **Input**: WAV, AIFF, SFZ, FLAC
- **Output**: VST3, .patchcraft packs
- **Sample**: Unlimited size, any format
- **Graphics**: PNG, JPG, SVG support
