3 — The Design canvas

The Design tab is where the GUI you ship to end users gets shaped. Drag elements onto a canvas, bind them to parameters, and arrange them visually.

Canvas anatomy

The canvas is a fixed-size virtual surface (default 1280×800). Whatever you put on it is exactly what your end user sees in the Player. Pick a canvas size from the toolbar dropdown — common pack sizes match standard plugin window sizes.

The Elements palette

Open the left sidebar's Elements tab. You can drag any of these onto the canvas:

Knob

The most common control. Bind to a parameter, choose a style preset (Vintage Gold, Modern Dark, etc.), or import a custom filmstrip PNG.

Slider

Vertical or horizontal. Same parameter binding system as knobs.

Button / Toggle / Dropdown

Discrete controls. Toggles work for stepped parameters; dropdowns surface enumerated values.

Drum Pad / Pad Grid

Single pad or 4×4 grid. Click triggers a MIDI note (default C1 + pad index). Velocity comes from click-Y position.

Keyboard

On-screen MIDI keyboard. Click to play.

Meter / Waveform

Live audio readouts driven by the engine's output peak.

XY Pad

2D control surface — bind X and Y to two parameters.

Tab Panel

Switches the canvas between sub-pages (e.g. Main / Amp / Filter / Mod). Each tab activates a named group.

Panel / Group / Shape / Image / Label

Visual grouping and chrome. Panels are containers; Groups are logical collections; Shapes are decorative; Image renders artwork; Label is text.

Drop, position, bind

  1. Drag from the palette

    The element lands at the canvas centre. Move it by dragging the body.

  2. Resize

    Drag the bottom-right corner of the selection. Hold ⇧ to constrain proportions.

  3. Bind to a parameter

    Right-click the element → Bind Parameter, or pick from the Inspector's Parameter dropdown. Right-click on empty canvas → Add DSP Control → [category] → [parameter] drops a knob already bound.

  4. Style

    Inspector lets you set knob style, label position, accent colour, filmstrip override.

Selection & alignment

Select multiple elements with Shift+click or marquee-drag. The canvas toolbar's alignment cluster activates whenever 2+ are selected:

ButtonAction
L / C / RAlign left / horizontal centre / right
T / M / BAlign top / vertical middle / bottom
DH / DVDistribute horizontally / vertically (3+ selected)
OrderBring forward / send back (z-order)

While 2+ elements are selected, the canvas overlays dashed alignment guides at top / middle / bottom edges plus pixel-distance labels for adjacent elements.

The Layers panel

Right sidebar → Layers tab. Lists every element in z-order. Use it to:

  • Shift-click for range select; Ctrl/⌘-click for toggle
  • Delete deletes the selected layers
  • Drag a layer onto a Group / Panel / TabPanel to re-parent
  • Drag between rows to reorder z-order
  • Toggle visibility with the eye icon, lock with the lock icon, opacity with the percentage
  • The ⤢ button pops the panel into a free-floating window so you can move it anywhere

Tab pages (multi-page layouts)

  1. Drop a TabPanel

    Add a TabPanel element. The Inspector shows a Tabs list — add labels like Main / Amp / Filter / Mod.

  2. Group elements per tab

    Select the controls you want on the Amp tab. Set their Group ID in the Inspector to amp (or click the matching tab in the canvas first — newly-added elements inherit the active tab's group).

  3. Click a tab to test

    Tabs in the canvas behave just like they will in the Player. Switching tabs hides the elements not on that group.

The Inspector

The right sidebar's Inspector tab shows the properties of whatever is selected. Common fields:

  • Label — visible text on knobs / labels
  • Parameter — which DSP value this control drives
  • Style / Knob Style — visual preset
  • Accent / Border / Background colour — per-element colour overrides
  • Position / Size / Opacity — exact numeric edits
  • Animation + Audio Reactive — make elements pulse/wobble in response to live audio

Right-click anywhere

The canvas right-click menu is the fastest way to add bound controls:

  • Add Container — Panel / Group / Tab Panel
  • Add Shape — Rectangle, Ellipse, Triangle, Diamond, Line
  • Add DSP Control — categorized submenus (Source, Filter, Amp, Mod, FX, Output) with every parameter the current engine exposes
  • Assign Selected To Parameter — same categorized list, applied to current selection
  • Align / Distribute, Arrange Order
Tip Make heavy use of Groups + tab-pages. A 30-knob layout is exhausting for users; tabs of 6–8 knobs each with clear sections (Amp / Filter / Mod / FX) feel professional.
