7 — Brand Lab

The single tab that turns your instrument into a product. White-label the Player chrome, set your identity, and play the live instrument inside a true-to-DAW preview.

Why it matters

The Brand Lab is the answer to "what does this look like as a sellable plugin?" — it's where the Test page (live audio + MIDI playback of your instrument) and the Branding form merge into one workspace. The right pane shows your actual instrument inside a Player-shaped frame; the left pane lets you edit the brand identity in real time.

What you can edit

Identity

  • Display Name — overrides the title-bar text in the Player
  • Tagline — short marketing line under the title
  • Creator — appears in pack metadata and About
  • Version — semver string for the pack
  • Website — clickable link in the Player's About
  • Logo Image — pick a PNG / JPG / SVG via the Browse... button. Replaces the default initial-letter plate in the Player chrome.

Skin colours

  • Accent — primary brand colour (knob outlines, highlights, borders)
  • Panel — secondary surface colour
  • Background — main fill
  • Text — body text colour

Each colour swatch opens a colour-picker callout when clicked; pick a colour, the live preview updates instantly. Reset to Default Colours restores the default PatchCraft skin.

Live preview

The right side of the Brand Lab is a Player-shaped frame:

  • Branded header strip at the top — logo plate, display name, tagline, creator + version on the right. This is exactly the chrome end users will see in their DAW.
  • Live instrument below — your actual designed layout, with the audio engine running. Click on-screen keyboard keys, drum pads, knobs — everything works.

Use the Show Branding Form toggle in the page header to hide the form column and see the player at full width. That's exactly what your end user sees.

Workflow tips

  1. Sketch identity first

    Set Display Name and pick an Accent colour before fine-tuning anything else — the rest of the design hangs off these choices.

  2. Pick a logo at full resolution

    The Player scales it down. Use a 256–512px square PNG with transparent background. SVG works too.

  3. Audition real notes

    While editing branding, play notes through the on-screen keyboard or a connected MIDI controller. Audio is live so you can A/B colour choices against the actual sound.

  4. Hide the form for a final review

    Toggle the form off — what you see is shipping.

Where the values are stored

Every field on this page writes to manifest.json in the project. When the Player loads a pack, it reads the manifest and applies branding before drawing the layout. So:

{
  "playerDisplayName": "MyBrand Drums",
  "playerTagline": "Hand-crafted percussion library",
  "playerLogoImage": "assets/logo.png",
  "playerAccentColour": "ffb14a2c",
  "playerPanelColour":  "ff15171b",
  "playerBackgroundColour": "ff0b0d10",
  "playerTextColour": "ffe6e6e6",
  "creator": "MyBrand",
  "version": "1.0",
  "website": "https://mybrand.example"
}

You can edit these by hand in the JSON if you prefer — the Brand Lab is just a friendly UI over the same fields.

Tip — Test in the actual DAW too The Brand Lab preview is faithful, but the final test is loading the exported pack into the Player VST3 inside a DAW like Reaper, Live or FL Studio. Treat that as your release gate.
