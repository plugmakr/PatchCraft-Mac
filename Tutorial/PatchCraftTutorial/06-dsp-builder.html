6 — DSP builder

For advanced patches: chain DSP blocks (filter, EQ, drive, delay, reverb, advanced FX), wire modulation routes, and capture the result as a Patch.

When you'd use it

Most workflows live on the Design tab — pick an engine, tweak its built-in knobs, save. The DSP Builder kicks in when you want:

  • A custom signal chain beyond the engine's defaults
  • Modular routing (e.g. a sidechain envelope into a different filter cutoff)
  • To capture a complete patch (engine + DSP graph + sample map + MIDI mappings) under a single name

Anatomy

  • Block list — every DSP module in the current patch (oscillator / filter / amp env / LFO / EQ / advanced FX / reverb / delay)
  • Edges — audio signal connections between blocks
  • Modulation — separate connections for control-rate routes (LFO → cutoff, env → pitch, etc.)
  • Macros — collected control points that surface as performance knobs
  • Quick-edit controls — per-section editors for source, filter, amp, mod, FX, output

Source matrix

Each engine type has a source matrix (oscillators for synth, sample layers for sampler, etc.). The mixer panel inside the DSP builder shows six channels per bank, with bank tabs to switch between groups. Use the bank tabs at the top of the DSP page.

Easy Mode

The right-hand Easy Mode panel is a quick-author area: pick a theme + variation, and the system applies a coherent set of values to every block in one click. The Add to Pack toggle attaches the resulting preset to the active expansion automatically.

Save Patch / Save Patch As

Inside the DSP page, the canvas toolbar shows two extra buttons:

  • Save Patch — overwrite the current patch with the live state
  • Save Patch As… — name a new patch (also adds it to the current expansion)

Patches differ from presets:

ConceptWhat it captures
PresetA snapshot of parameter values keyed by id (e.g. cutoff = 4200). Cheap, fast, host-automation friendly.
PatchThe full instrument state: engine, DSP graph, sample zones, MIDI mappings, parameter values. Backs up an entire instrument variant.

When the Player loads a preset that's linked to a patch, the patch state restores first, then the preset's values overlay.

Modulation routes

Each modulation entry has a source (LFO / envelope / macro / MIDI), a destination (any DSP parameter), depth, polarity (uni/bi), and an optional curve. Right-click in the routes list → Add modulation to create a new route.

Where this is going A real visual modulation matrix UI is on the roadmap. Today the routes are managed via the routes list and the macros panel.
