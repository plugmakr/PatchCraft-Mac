2 — Getting started

From cold install to a brand-new project ready to author.

Install

  1. Run the Studio installer

    Double-click PatchCraft Studio.exe (or your platform's equivalent). On first launch the app generates a default instrument so the canvas is never blank.

  2. Drop the Player VST3 into your DAW's plugin folder

    Typical Windows path: C:\Program Files\Common Files\VST3\. macOS: ~/Library/Audio/Plug-Ins/VST3/. Rescan plugins inside your DAW.

  3. (Optional) install a starter pack

    Place any .patchcraft folder in the same directory as the Player .vst3. The Player auto-discovers nearby packs.

Create a new project

  1. File → New Project

    The current project closes (you'll be prompted to save unsaved changes). A blank project loads with the default Sampler engine.

  2. Pick the engine

    In the Canvas toolbar's Engine dropdown, choose Sampler / Synth / Drum Machine / FX. The canvas reloads with that engine's starter layout and starter sound.

  3. File → Save Project As…

    Pick a folder. Everything from here writes into that folder: layout, presets, samples, all assets.

Important Save the project early. Some workflows (importing samples, saving patches) require an on-disk project folder. The Studio will prompt you if it needs the project saved first.

Default project layout

Every fresh project ships with:

  • A title label, preset dropdown, hero image area, tab strip
  • Engine-specific starter knobs (e.g. ADSR + filter for sampler)
  • An on-screen MIDI keyboard at the bottom
  • The synth engine bundles 50 hand-authored trance / electronic / psytrance presets
