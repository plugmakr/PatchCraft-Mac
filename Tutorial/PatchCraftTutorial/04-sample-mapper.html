4 — Sample mapper

Map sample files to MIDI keys / pads / velocity layers, edit the waveform, and turn one sample into 16 chops.

Importing samples

Three ways to bring audio into a project:

  1. Top toolbar → Import Samples

    Pick one or many audio files. PatchCraft infers root notes from filenames (e.g. Pad_C3_127.wav sets root=C3, velocity=127), and audio analysis fills in the rest.

  2. Drag-drop a folder onto the Sample Mapper

    The mapper recurses one level deep, picks up every WAV / AIFF / FLAC and maps them in one go. The fastest way to import a kit.

  3. Sample Mapper toolbar → Import button

    Same as the top-toolbar option, scoped to the mapper view.

The waveform editor

Click any zone in the mapper to open it in the waveform editor below. You can:

  • Trim — drag the purple sample-start / sample-end handles. Releasing snaps to the nearest zero-crossing (hold Shift to bypass).
  • Loop — toggle the Loop button, then drag the green loop-start / loop-end handles in the waveform.
  • Fade in / out — click + Fade In / + Fade Out to add fade regions, then drag the blue / orange handles.
  • Reverse — toggle the Reverse button. The waveform mirrors so you see what the engine plays.
  • Zoom — Ctrl/⌘+wheel zooms (cursor anchored). Plain wheel scrolls. Bottom scrollbar pans long samples.
  • Time ruler at the top shows seconds with auto tick spacing.

Per-zone parameters (Inspector)

With a zone selected, the inspector exposes everything the engine reads:

  • Root / Low / High Note — pitched playback range
  • Low / High Velocity — velocity layer split
  • Round Robin Group / Index — multiple zones at the same root rotate
  • Pad Index / Pad Label / Choke Group / One Shot / Trigger Probability — drum-pad authoring fields
  • Gain dB / Pan / Pitch Offset / Reverse / Priority — per-zone playback edits
  • Sample Start / End / Loop Start / End / Fade In/Out — bounds (matched to waveform handles)

Building a drum kit, end to end

  1. Switch to the Drum Machine engine

    Canvas toolbar → Engine → Drum Machine. The canvas reloads with a 4×4 PadGrid + drum-tuned macros.

  2. Drag a folder of one-shots onto the Sample Mapper

    Kicks, snares, hats, percs — any organisation works.

  3. Apply Preset → 16 pads from C1 (one-shot)

    Samples land on MIDI 36-51. The engine plays them as one-shots; hats auto-share choke group 1 so closed-hat cuts off open-hat.

  4. Refine zone-by-zone

    Click a pad to load it into the waveform editor. Trim, set gain, tweak choke group as needed.

  5. Test in the Brand Lab

    Switch to the Brand Lab tab. Click pads or hit MIDI notes 36-51 — you hear the kit.

Multi-sample patch (key-mapped)

  1. Switch to Sampler engine

    Reload starter layout for keyboard playing.

  2. Import a folder of pitch-labelled samples

    Filenames with notes (Pad_C2.wav, Pad_E2.wav) auto-detect root notes.

  3. Apply Preset → Build Multi-Sample Patch

    The mapper distributes zones across the keyboard so each note interpolates from the nearest sample.

  4. (Optional) add velocity layers

    For instruments with multiple dynamic levels, set Low/High Velocity per zone so the engine picks the right layer per note.

Tip For round-robin (multiple takes of the same note), the Apply Preset dropdown auto-detects same-root duplicates and assigns them to a round-robin group. You can also set this manually per zone.
