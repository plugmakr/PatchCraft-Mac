10 — Glossary

Quick reference for every term used in PatchCraft.

Brand Lab

The Studio tab that hosts the live Player preview plus the branding form. White-labeling lives here.

Canvas

The fixed-size virtual surface (default 1280×800) on the Design tab where elements are arranged. The end-user sees this exact layout in the Player.

Choke Group

An integer ID on a sample zone. Voices in the same choke group cut each other off — used so a closed hi-hat silences an open hi-hat.

DSP Block

A unit of audio processing in the DSP graph: oscillator, filter, amp envelope, LFO, EQ, drive, delay, reverb, advanced FX. Blocks connect via audio edges and modulation routes.

DSP Graph

The full network of DSP blocks, audio edges, and modulation routes that defines a patch. Each engine has a default graph; users can author custom graphs in the DSP Builder tab.

Element

A single visual control on the canvas: knob, slider, button, drum pad, label, image, etc. Each carries layout (x/y/w/h), styling, and an optional parameter binding.

Engine

The audio engine type: Sampler, Synth, Drum Machine, FX. Determines what parameters exist and how notes are rendered.

Expansion (or Expansion Pack)

A grouping of patches and presets shipped together as add-on content for an existing Player. Has metadata (name, brand, artwork, version) and a list of included assets.

Filmstrip

A vertical (or horizontal) PNG with N stacked frames, used to render a custom knob/slider/meter as if it were animating through frames. The Library tab manages these.

Glitch Kit

A Sample Mapper preset that slices one long sample into many small zones (transient-detected or grid-aligned), assigning each slice to a pad or chromatic key.

Layout

The full set of canvas elements that make up the GUI. Persisted as layout.json in the pack.

Manifest

The pack's identity card: instrument name, creator, engine, version, branding fields (player display name, tagline, logo, colours). Persisted as manifest.json.

Parameter

A named, ranged value the engine reads. Each has an id (filterCutoff), a min / max / default / step, a category (Filter / Amp / Mod / FX / …), and a unit. Knobs and sliders bind to parameters.

Patch

The full instrument state captured under a name: engine, DSP graph, sample zones, MIDI mappings, parameter values. Heavier than a preset.

Pack (.patchcraft)

The exported folder shipped to end users. Contains manifest, layout, parameters, presets, mappings, samples, assets, expansion metadata.

Player

The runtime VST3 / standalone plugin that loads a pack and renders its layout for end-users in their DAW.

Preset

A snapshot of parameter values keyed by id. Lighter than a patch — meant for fast browsing in the Player. Each preset can optionally link to a patch for full state restoration.

pScript

A project-level automation language saved as pscript.txt. It can react to preset loads, notes, mod wheel, timers, and mapped knob movement in the Player.

Round Robin

A grouping where multiple sample zones at the same pitch alternate on each note-on, simulating the variation of repeated takes on a real instrument.

Sample Zone

One mapped sample with key range, velocity range, root note, loop points, fades, gain, choke group, pad index, etc. The Sample Mapper edits these.

Studio

The desktop authoring app. Where instruments are designed, branded and packaged.

TabPanel

A canvas element that switches between named groups of elements. Tab labels generate a group ID; child elements with that group ID become visible only when that tab is active.

Velocity Layer

A sample zone whose Low/High Velocity range is narrower than 1-127, so only certain incoming velocities trigger it. Multiple zones at the same pitch with different layers create dynamics.

Wavetable

A multi-frame oscillator shape. The Synth engine carries 9 built-in tables plus a custom 4-frame editor. Position, morph, warp, fold, bend, sync are real-time parameters.

Zero Crossing

A sample where the audio waveform crosses zero amplitude. Setting trim / loop bounds at zero crossings prevents audible clicks. The Sample Editor snaps to the nearest one on mouse-up.
