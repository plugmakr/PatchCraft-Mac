Sampler, MIDI, and Runtime Drop Workflows

This guide shows how to use the new sample and MIDI features in PatchCraft: targeted sample drops, drum-pad mapping, MIDI files that drive sample zones, Slice mode chopping, runtime sample libraries in the Player, and the One Shot Maker handoff.

Start with the fastest path Jump to Slice mode

What Changed

1. Drop Audio

Drag WAV, AIFF, or FLAC onto pads, zones, or the runtime library.

2. Pick Target

Pad drops map to pad notes. Zone drops map to that zone. Library drops auto-place.

3. Assign MIDI

Drop or assign a MIDI file to a zone or pad.

4. Choose Mode

Trigger, Pitch, Slice, Drum, or Mod decides how MIDI affects the sample.

5. Test Runtime

Brand Lab and exported Player use the same active sample/MIDI routing.

Core idea A sample zone is now more than an audio file. It can also carry a MIDI file, playback mode, transpose, velocity amount, host-sync behavior, pad assignment, and performance metadata.

Fastest Path: Build a Playable Drum Kit

  1. Open Sample Mapper

    Use a blank project or a drum/sampler template. Stay in the Sample Mapper for the first pass.

  2. Drag drum samples onto the pad area

    Drop one sample per pad. By default, PatchCraft maps one sample to one pad instead of stacking everything.

  3. Switch to Drum Map if needed

    The drum map uses pad notes starting at C1. Pads should trigger the imported samples directly.

  4. Add MIDI if you want a pattern

    Drop a MIDI file onto a pad or zone. The MIDI becomes the trigger pattern for that sample or pad.

  5. Open Brand Lab and press Play

    The drum grid should trigger the same pad slots. If the Player library is present, runtime users can also drop samples there.

MIDI Modes: Which One Should I Use?

Trigger

Every MIDI note triggers the selected sample zone at its root note.

Use for: one sample played rhythmically.

Pitch

MIDI notes keep their pitch and play the sample engine melodically.

Use for: riffs, basslines, melodies, and tuned instruments.

Slice

Different MIDI notes select different slices of one sample while the rhythm comes from the MIDI file.

Use for: Serato-style chops, vocal cuts, breaks, loops, and phrases.

Drum

MIDI maps to pad slots and drum rows.

Use for: drum kits and imported drum patterns.

Mod

MIDI is used as a performance/modulation source instead of only notes.

Use for: future performance routing and expressive controls.

Simple choice If you are unsure, use Trigger for one-shot loops, Pitch for tuned playing, Slice for chopping one long sample, and Drum for pad kits.

Slice Mode: MIDI-Controlled Sample Chopping

Slice mode is the new important path. It lets one sample behave like a playable chop instrument. The MIDI file supplies rhythm and note lanes. PatchCraft turns those unique MIDI notes into slice indexes.

How Slice mode thinks

Long Sample

Vocal phrase, drum break, loop, texture, guitar riff, or one-shot with movement.

Slice Count

PatchCraft splits the playable region into equal slices for this pass.

MIDI Notes

Unique MIDI notes choose slice 1, slice 2, slice 3, etc.

Playback

The root sample triggers, but each hit jumps to the chosen slice.

How to build a Slice instrument

  1. Import or drag in one sample

    Use a vocal phrase, drum break, melodic loop, or texture with clear movement.

  2. Select the zone

    Click the sample zone in the key zone editor or zone list.

  3. Assign a MIDI file

    Use Assign MIDI in Advanced Playback, or drag a MIDI file onto the selected zone.

  4. Set MIDI Mode to Slice

    The MIDI note lanes become slice selectors. Velocity still affects hit level.

  5. Press Play in Brand Lab or Player

    The playhead follows the MIDI pattern and each trigger jumps to its slice.

Current limitation Slice mode currently uses equal slice regions from the sample zone. For transient-aware slicing, first use the Sample Mapper slice tools to create mapped slices, or wait for the next pass where transient markers become first-class runtime slice points.

One Shot Maker Handoff

The One Shot Maker can render plugin or instrument sounds into a pack, then hand that rendered pack to the Sample Mapper as the active source.

Load Plugin

Create or capture source sounds.

Render Pack

Generate one-shots or chromatic samples.

Review Audio

Preview, trim, reject bad renders.

Send to Mapper

Stops/closes live plugin host and opens Sample Mapper.

Active Source

The rendered pack becomes the current project's sample source.

Build Recipes

Recipe 1: Serato-style vocal chop

  1. Open Sample Mapper and import a vocal phrase.
  2. Select the zone and trim the playable start/end.
  3. Assign a MIDI file with several unique note lanes.
  4. Set MIDI Mode to Slice.
  5. Lower MIDI Velocity Amount if the hits jump too much.
  6. Add filter, delay, and reverb controls on the Design page.
  7. Test in Brand Lab while DAW sync or internal Play is running.

Recipe 2: Drum machine with user-swappable pads

  1. Add a Pad Bank and Runtime Sample Library to the Player UI.
  2. Map factory drum one-shots to C1 and up.
  3. Use the drum pattern grid to trigger pad slots.
  4. Expose per-pad Tune, Volume, Pan, Filter, and Send controls.
  5. In Brand Lab, drag a new sample onto a pad and confirm it plays immediately.
  6. Export and test the VST3 in a DAW with dragged replacement samples.

Recipe 3: MIDI-controlled one-shot instrument

  1. Render or import a crisp one-shot.
  2. Map it to a zone with one root note.
  3. Assign a MIDI groove to the zone.
  4. Use Trigger mode so every note triggers the same sample.
  5. Add macro controls for attack, release, filter, delay, and drive.
  6. Create presets by changing the sample, MIDI file, and DSP chain together.

Recipe 4: Tuned sample phrase

  1. Import a tuned sample or multisample set.
  2. Set root notes and key ranges.
  3. Assign a MIDI melody.
  4. Use Pitch mode so MIDI notes stay melodic.
  5. Use MIDI Transpose to fit the phrase to the sample range.
  6. Add scale-safe presets and test the low/high key ranges.

Troubleshooting

ProblemLikely causeFix
Pad plays a tone instead of my sample.The pad is not mapped to a sample zone, or the sample overlay is not active.Drop the sample onto the pad again, verify pad index/root note, and retest in Sample Mapper.
MIDI does not trigger the sample.MIDI file is assigned to the wrong zone or transport is stopped.Select the zone, check MIDI Path and Mode, enable Host Sync, then press Play.
Slice mode sounds like one repeated sample.The MIDI file only has one unique note lane or slice count is effectively one.Use a MIDI file with multiple notes, or edit the MIDI so different notes select different slices.
Export validation fails.A sample or MIDI file path is missing.Open Sample Mapper health/readiness, relink missing files, then export again.
Runtime sample drops do not persist.Runtime imports live in the host session/user content store, not the factory sample map.Save the DAW session. For factory content, import samples in Studio and export the pack.
Pattern plays out of time.Host Sync or BPM source is wrong.Enable Host Sync for loop-style playback and confirm DAW transport is running.
