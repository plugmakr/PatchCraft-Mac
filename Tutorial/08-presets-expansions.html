8 — Presets & expansions

Save sounds. Group them. Sell more sounds later.

The Preset Browser (Design tab)

The Design tab's right column is a card-style preset browser. Each row shows:

  • Coloured stripe on the left indicating the preset's category (Lead / Bass / Pad / Arp / FX / Mod / Pluck)
  • Index number, preset name in bold, description underneath
  • A category pill on the right side
  • A star marker on the default preset

Above the list:

  • Search box — filter by name, description, or tag substring
  • Category chips — click a chip to narrow the list to one category; click again to clear
  • Pop-out — the ⤢ button detaches the panel into a free-floating window so you can move it anywhere

The buttons at the bottom:

ButtonDoes
NewCapture the current live sound as a brand-new named preset
SaveOverwrite the selected preset with the live values
Save As…Duplicate live sound into a new named preset
GenerateAuto-generate themed presets via the PresetGenerator
What ships out of the box The Synth engine bank ships with 50 hand-authored trance / electronic / psytrance presets spanning leads (Stadium Supersaw, Trance Hands Up, Goa Lead, …), arps (Trance Gate, Liquid Arp, …), basses (Psy Bass, Acid Bass, Sub Drop, …), mod-textures, and pads. They're a usable starter library and a worked example of preset authoring.

Saving a patch

Saving a "patch" (full instrument state, not just a parameter snapshot) happens via the canvas toolbar's Save Patch / Save Patch As… buttons (visible when the DSP Builder tab is active).

Critically: saving a patch auto-attaches it to your active expansion pack. If no expansion exists yet, one is auto-created with the name <instrument> Pack. You don't have to remember to manually add patches to packs — it just happens.

The Expansion Library

Left sidebar → Expansions tab. A card grid showing every expansion in the project:

Per-card content

Thumbnail (artwork or auto-generated initial plate), expansion name, brand / author, count of patches and presets.

Click to select

Selected expansion is the target for new Save Patch calls.

Double-click

Jumps to the DSP Builder focused on this expansion's patches.

+ New

Create a new named expansion from a popup dialog.

Pop out

The ⤢ button floats the library panel as a separate window.

What an expansion contains

An ExpansionMetadata is the project's grouping unit. Each one carries:

  • id / name / description / brand / author / category / version
  • artworkPath — pack thumbnail (PNG / JPG)
  • licensePath — text license file shipped with the expansion
  • tags, folders (preset categories like Arps / Bass / Pads / FX)
  • includedPatchIds / includedPresetNames — which patches and presets belong to this pack
  • includedAssets — every file (samples, knob filmstrips, artwork) the expansion depends on

Distribution model

  1. Branded Player + Core pack

    You ship your white-labelled PatchCraft Player.vst3 bundled with one default expansion (e.g. MyBrand Core). Customers buy this once.

  2. Build additional expansion packs

    For each, design new patches in Studio (often using the same engine), save them into a new expansion. Export each as a .patchcraft folder.

  3. Customers drop expansion folders into their Player

    The Player auto-discovers them in its packs directory. Each appears in the library browser as a card the user can browse / load presets from.

Tip Treat the Core expansion as the entry-level product (a useful library by itself). Reserve the deepest, most niche sounds for paid expansions — that's where the recurring revenue lives.
