5 — MIDI playground

Build phrases, arpeggios, drum patterns, and chord progressions that the instrument can play on its own. Deterministic — no random generation.

What's on the page

The MIDI Playground page hosts three editor views, switchable via the Editor View dropdown:

  • Output Lane — step-based editing of note / velocity / gate / probability lanes (the original view)
  • Piano Roll — 6-octave roll with real piano keys, beat markers, hover highlight, note labels
  • Drum Pattern Grid — multi-track step grid for drum-machine blocks

Status strip + global controls

Above the editor, a status strip shows the current scale, step count, and edit mode. Below it sit the controls for:

  • Scale & root — sets the diatonic scale used by chord operators / scale-quantize
  • Steps / Rate / Gate / Swing / Probability / Humanize / Velocity Curve — per-pattern playback parameters
  • Chord size / spread / strum / flam — chord-mode voicing controls
  • Mutation / Ratchet — variation parameters (deterministic — pattern stays stable across plays)

Click the Operators button. A categorized popup appears:

All operators are deterministic: same input + same operator = same output. Combine them to build phrases without ever rolling a dice.

Phrase library

Click Phrases. A categorized list of 20 hand-authored 16-step phrases pops up:

  • Trance / Electronic — Driving 8th-note root, Off-beat octave bounce, Trance arp climb (1-3-5-1), Goa pulse, Acid bassline (1-5-3-7), Pluck riff (descending 5ths), Roll-up (chromatic), Anjuna lead (4-5-1-2), 16th hat, Triplet feel
  • Bass / Lead — Two-octave run, Skipping 5ths, Power-fifth stab, Sub-octave drop, Walking bass
  • Atmospheric / Pad — Sustained root, Slow octave alternate, Suspended 4th swell, Whole-note progression frame, Sparse melodic skeleton
  • Clear pattern at the bottom of the menu

Chord progression composer

Pick a progression from the Progression dropdown (I-V-vi-IV / ii-V-I / vi-IV-I-V / etc.), pick a root + scale, and click Apply Prog. The composer fills the steps with the chord notes for the chosen progression.

Piano Roll editor

Switch Editor View to Piano Roll. The view:

  • Spans 6 octaves (-36 to +36 semitones from root) with a real piano-keyboard column on the left
  • Beat lines emphasised every 4 steps; bar headers at the top
  • Hover the cursor to see a target cell highlight in accent colour
  • Click to draw a note · Ctrl/⌘-click to toggle · Right-click to clear
  • Shift-drag horizontally edits gate length within the step

Drum Pattern Grid

For Drum Machine instruments. Multi-track grid (one row per pad), 16-64 step columns. Click a cell to toggle, drag for ranges. Vertical strokes inside a cell scale velocity by Y. Tracks support pattern banks (8 patterns per kit), per-step velocity, gate and probability.

Export the pattern

Click Export MIDI to write the active pattern as a standard .mid file you can drop into any DAW.

Tip Build phrases by stacking operators. Start with Phrase: Trance arp climb, apply Transpose +7, then Scale-quantize. The result is reproducible, musical, and yours.
