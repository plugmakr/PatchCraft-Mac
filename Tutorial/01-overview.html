1 — What is PatchCraft

PatchCraft is a two-app system for building, branding and selling virtual instruments. The Studio is where authoring happens; the Player is the runtime your end users load in their DAW.

The two halves

PatchCraft Studio

Desktop authoring app. Engineers a custom instrument from scratch — sound design, GUI design, sample mapping, MIDI sequencing, branding and packaging. Output: a .patchcraft pack folder.

PatchCraft Player

VST3 / standalone runtime. Loads a .patchcraft pack and renders the layout the Studio designed, complete with live audio engine, MIDI input, host automation, MIDI Learn, and library browsing for expansion packs.

Engines

Every instrument is built on one of four engines. The engine determines what kinds of sounds the instrument can make and which parameters are available:

EngineBest forNotable controls
SamplerMultisample instruments, cinematic, orchestral, vocalKey zones, velocity layers, sample start/end, loop, fades
SynthSubtractive + wavetable synthesis. 50 trance/electronic presets ship.2 oscillators, sub, noise, wavetable, filter, ADSR, LFO
Drum MachinePad-grid samplers, MPC-style kits16-pad grid, choke groups, one-shot, round robin
FXAudio effect plugins (delay, reverb, drive)Drive, filter, delay, reverb, mix
Why pick the engine first? Switching engines wipes the layout because the parameter palette changes. Decide early.

The Studio's six tabs

Once a project is open you'll spend your time across these tabs. Each one is covered in detail in the upcoming sections:

  • Design — visual GUI layout + parameter list + preset bank
  • Sample Mapper — keyboard / velocity / pad mapping for sampled sounds
  • MIDI Playground — phrase tools, deterministic transforms, piano roll
  • DSP Builder — advanced patch builder for chained DSP blocks
  • Build — knob/slider/meter image builder for custom looks
  • Brand Lab — Player white-labeling + live preview + audio testing

The two side panels

Permanent on either side of the canvas:

  • Left sidebar — Elements (drag-to-canvas), Library (your knob/slider images), Expansions (card grid of packs).
  • Right sidebar — Inspector (selected element properties) and Layers (z-order tree). All panels are dock/undock-able.
Tip Click the ⤢ icon in any panel header to pop it out into a free-floating window you can move anywhere on screen.

The end-user loop

  1. Customer installs your branded Player VST3

    The same binary, but the manifest replaces the title bar, logo, accent colour and tagline.

  2. Player auto-loads the bundled pack

    The instrument appears with your custom layout and presets.

  3. They play, sweep knobs, MIDI Learn, automate

    Standard DAW workflows. Every visible control is host-automatable.

  4. They drop in expansion packs to grow the library

    Each new .patchcraft folder shows up in the library browser — sell more sounds, no code change.
